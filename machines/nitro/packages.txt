# Acer Nitro 16 (AN16-51): Intel i7-13620H + NVIDIA RTX 4050 Laptop, hybrid graphics.
# The desktop runs on Intel; NVIDIA is used only for apps that ask for it.

# Sound card: Intel SOF (Sound Open Firmware); internal audio doesn't work without it.
sof-firmware

# Intel integrated graphics
vulkan-intel # Vulkan
intel-media-driver # Hardware video decoding (VA-API; Broadwell and newer)

# NVIDIA (prebuilt for the linux kernel). Not included in the initramfs (40-nos-omit.conf).
nvidia-open
nvidia-utils
nvidia-prime # prime-run <app>: runs the app on NVIDIA
switcheroo-control # Right click > "Run using dedicated graphics card" in KDE
