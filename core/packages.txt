# Tools
fish
fastfetch
distrobox
podman
python
gum # UI of the first-boot setup screen (nos-firstboot)
keyd # Key remapping, can also be per window (e.g. ESDF → WASD in Sober/Roblox). Config in ~/.config/keyd/app.conf, see README

# Virtualization (QEMU/KVM)
qemu-desktop # Runs the VMs; with display (SPICE), audio and USB passthrough. qemu-base has no display support, virt-manager can't show a screen
libvirt # Service that manages VMs and their networks. The virt-manager UI (Flatpak) connects to it
dnsmasq # VM networking (the libvirt NAT network uses it for DHCP/DNS)
edk2-ovmf # UEFI boot in VMs (required to test the nos image)
swtpm # Virtual TPM (for Windows 11)
